# attic/

Архив старых наработок. Не используется в текущем (Fedora) пайплайне.

- `pmos/` — пакеты Nura (postmarketOS) `device-xiaomi-uke`,
  `linux-postmarketos-qcom-sm7675`, `firmware-xiaomi-uke`. Оставлены для истории;
  pmOS-порт отложен из-за региональных ограничений и AI-политики (см.
  `docs/FEDORA-PIVOT.md`).
- `deviceinfo` — черновик deviceinfo для pmOS.
