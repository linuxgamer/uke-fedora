# `kernel/files/` (Archived Palawan 7.2 Work)

`sm7675-xiaomi-uke.dts` is a draft board DTS based on `lamma-qrd.dts` and checked
against Xiaomi downstream sources. It belongs at
`arch/arm64/boot/dts/qcom/sm7675-xiaomi-uke.dts` in the Palawan source tree.

The DTS, O82 panel driver, and NT36532 touchscreen driver compile but have not
been tested on hardware. They are retained for a future port to the supported
ztsubaki v6.12 tree. See `docs/BRINGUP-NOTES.md` for context.
