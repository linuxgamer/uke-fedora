# Uke Kernel Source

This directory contains the complete corresponding source for the kernel binaries
published by this project, except for the unmodified upstream Linux v6.12 base.
The exact upstream commit, patch and config hashes are recorded in
[`SOURCE-MANIFEST`](SOURCE-MANIFEST).

## Contents

| Path | Purpose |
|---|---|
| `patches/uke/` | Complete patch series for the Uke platform, USB, RPMh, SMMU, GDSC, and UFS work |
| `configs/uke.config` | Exact arm64 kernel configuration for the published images |
| `modules.load` | Initramfs module load order for the published kernel ABI |
| `prepare.sh` | Creates a fresh upstream v6.12 tree and applies the patch series |
| `build.sh` | Builds `Image.gz`, modules, and an installable module staging tree |
| `package-source.sh` | Creates a complete patched Linux source tarball for a binary release |

## Rebuild

```sh
kernel/prepare.sh
kernel/build.sh
```

The default source path is `build/ztsubaki/linux`, output path is
`build/ztsubaki/out`, and installed modules are staged at
`build/ztsubaki/modules/`. `prepare.sh` refuses to overwrite an existing tree.

## Source Releases

Every binary release must include the source archive generated by:

```sh
kernel/package-source.sh --out build/release
```

The resulting `linux-6.12-uke-source.tar.zst` contains the full upstream v6.12
source with the Uke patch applied, the exact release config as `UKE-CONFIG`, and
the initramfs module list as `UKE-MODULES-LOAD`.
