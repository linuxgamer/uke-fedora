# device/

Device-specific данные для `uke`.

| Подпапка / файл | Содержимое |
|---|---|
| `deviceinfo` | черновик deviceinfo для Nura |
| `udev/` | правила udev (права, датчики, зарядка) |
| `ucm/` | конфиги ALSA UCM |
| `firmware/` | **списки** firmware/модулей и пути (не сами блобы) |

Раскладку разделов, AVB и стоковые DTB/DTBO держать здесь как справку.
Блобы не коммитить — только списки и способы извлечения.
